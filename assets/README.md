# assets/ — 换成你自己的立绘和动图（可选）

把文件丢进这个目录就行，**不用改代码、不用重启**（路由每次请求现查）。
文件名（不含扩展名）就是槽位名：

| 槽位 | 用在哪 | 建议格式 |
|---|---|---|
| `avatar.*` | 面板左上角头像、空状态的大图 | 抠好的**透明 PNG** 最好 |
| `writing.*` | 点「写日记」之后，中间那张图 | **透明底 GIF**（会自己动） |

扩展名按这个顺序取第一个存在的：

```
png → webp → gif → apng → jpg → jpeg → svg
```

PNG 排最前，因为抠好的人像通常是透明 PNG。所以**不要同时放 `avatar.png` 和 `avatar.gif`**
（会取 png）；想用动图就只放动图那一个。

## 例子

```
assets/avatar.png     ← 左上角头像换成这张抠好的图
assets/writing.gif    ← 写日记时中间放这个会动的透明 GIF
```

删掉文件就还原成内置的手绘 SVG。

## 几点提示

- **透明底很重要。** 界面里这两种图都不垫背景色，抠干净了才好看；留着白底会顶着一个白方块。
- **别太大。** 头像按 46×46（标题栏）/ 96×96（空状态）显示，动图最大 150×150。
  原图 200–500px 就够，太大的 GIF 会拖慢加载。
- 显示时用 `object-fit:contain`，所以方图不会变形。
- 侧栏那颗小图标**不跟着换** —— 它是内联的 `currentColor` 单色 SVG，要跟着主题变色；
  换成位图在深色模式下会糊成一团（这是第一版踩过的坑）。
- `README.md` 自己不会被当成素材（扩展名不在白名单里）。
- 槽位名只允许 `A-Z a-z 0-9 _ -`，最长 32 字符；路径穿越在服务端直接被挡掉。

## 头像为什么要裁

界面用 `object-fit:contain` 显示头像，图里留多少透明边距，主体就按比例缩多小。
第一版 `avatar.png` 是 300×300、内容只占 244×185，等于白留了 68% 的透明面积 ——
在 46×46 的标题栏里人物小得几乎看不清。

而且光裁掉边距也不够：内容是**横向**胸像，塞进正方形后竖向最多只能填 65%。
头像真正要的是**脸**，所以 `scripts/trim-avatar.py` 做的是对着头部特写裁切
（`zoom=0.75 focus=0.50`，实测在 46px 下最清晰）。

```bash
# 重新裁（会先备份原图，可反复跑）
python scripts/trim-avatar.py
python scripts/trim-avatar.py --zoom 0.9               # 放松一点，多留身体
python scripts/trim-avatar.py --zoom 1.0 --focus 0.5   # 退回"整幅内容居中"

# 按 46/64/96 真实尺寸渲染候选裁切，人工挑
python scripts/avatar-candidates.py

# 核验所有素材：格式 / 尺寸 / 帧数 / 真实透明通道 / 主体是否偏心
python scripts/check-assets.py
```

**原图备份在 `assets/.original/`**（目录名以点开头，不在素材扫描范围内），
所以随便怎么裁都能回到原样 —— 直接复制回去覆盖 `avatar.png` 即可。
